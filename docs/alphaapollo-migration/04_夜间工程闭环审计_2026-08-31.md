## 可以复查的真实流程案例

免费 scripted provider 的真实 Docker 案例不是模型 baseline 复现，而是控制链测试：

`固定语料查询/公开模拟 → 同一分支下一轮 → 封闭候选 → 公开 validation → 选择 → freeze → 单次 final score`

- AA061：mini-swe、Reasoning tool-call、Reasoning JSON 三种路径；先请求缺文件
  的反馈，随后补齐候选并成功获得独立公开回执，最终只评分一次。
- AA065：两模型两轮，4 个独立分支；公开 docs 回应在分支内可见，初始提示不
  包含 corpus 全文；最终结果记录所有分支成本和唯一 selected candidate。
- 本地可恢复证据位于 ignored `benchmark-vabench-release-v4/reports/` 下
  `aa061-waveform-reviewed-01`、`aa064-evolution-surface-01`、`aa065-evolution-docs-01`
  和 `overnight-final-integration-01`。raw private traces 不进 Git，不自动发给模型或上传服务。
