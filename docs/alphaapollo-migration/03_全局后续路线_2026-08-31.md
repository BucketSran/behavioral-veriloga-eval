## 全局队列与验收

| 方向 | 当前能力 | 剩余验收 / 边界 |
| --- | --- | --- |
| Harness 可信执行 | controller、权限、预算、freeze 和隔离已接通 | 新工具复用预算与事件；验证超时/取消/清理失败。Bash marker 只能作诊断，不能充当可信调用证据 |
| 波形反馈 | AA-VAE-058 parser；AA-VAE-060 独立执行器已验证 | 显式 native 公开反馈 → 轨迹/评分身份校验。不能从共享旧 CSV 补当前候选标签 |
| RAG | AA-VAE-057 synthetic corpus 接通两种 native backend | 真实语料逐项来源/许可/排除；再冻结 campaign、Evolution 与匹配条件。不能将公开可读等同许可或无污染 |
| Reasoning / Evolution | AA-VAE-046/049 运行编排与确定性测试 | 新工具保持匹配权限；共享反馈、选优与全分支成本有据可查；真实模型质量另做实验 |
| Coding-agent 借鉴 | 已采纳公共控制、环境、工具、状态分层 | 评估结构化 read/edit/test 相对 Bash 的实际收益；接口/差分方案未冻结，不为凑功能直接新造工具 |
| SFT/RL 扩展 | AA-VAE-059 synthetic projection/validator | 独立 trajectory adapter、split/去重/来源验证；真实导出、reward、训练栈及费用需另冻方案，不使用 r53/final evidence 训练 |
| 公平性与消融 | 已有条件/预算契约与协议差分 | 审计提示词、工具、文档和安装 examples。Agentic/No-EVAS 的包内 examples 不同；不能将环境资料差异全归因于 EVAS 执行 |
| 真实模型实验 | DeepSeek pilot 安全中止，无有效评分提交 | 新批准预算下先小规模运行验证，再分别比较 backend、Evolution、RAG、波形。保留失败/中止分母，不自动付费重跑 |
| 结果与 case study | AA-VAE-048 ledger/paired/claim gate | 完善图表、成本、不确定性、失败分类及来源引用；用完整案例逐步关联模型动作、候选、公开反馈、freeze、终评 |
| 审计文档与 CI | 台账、功能笔记、多层 smoke 已有 | 每个切片独立 commit，记录代码/测试/来源/限制。旧状态保留时间戳，不把历史缺口反复计作当前未实现 |

## 顺序与可并行范围

1. 先完成可信性/公平性基础：当前波形执行器、匹配信息面的只读审计。
2. 执行器通过后，另立 native 接线小计划；RAG、训练转换各自冻结测试与输入边界。
3. 同步完善报告和 case study，避免只有“测试全绿”而无法人工追踪行为变化。
4. 真实模型实验与训练分开批准。无真实数据/预算的 fixture 不能代替质量证据。

主线程统一拥有共享 schema/controller/launcher/scorer、文档与 Git；独立模块
可另行登记精确文件归属后并行。只读审查可与实现并行，不开重复写入者。
当前夜间自动续进只执行已冻结的波形执行器及后续经审查的 native 接线，
其余队列不是无界开发授权。r53 + EVAS 0.8.7、旧工作树和 stopped pilot 保持原样。
