## 顺序与可并行范围

1. 先按最新审计页复核 AA-VAE-061–066 的独立 diff、测试与案例，不重复开发这些已完成接口。
2. 决定正式扩展实验的匹配信息面/预算，以及 waveform 进入 Evolution 时的共享和选择规则。
3. 按需提供并审核真实 RAG 来源、许可和污染排除；工具目录/read/edit 需求仍需领域讨论。
4. 新真实模型实验、真实语义轨迹导出与训练分开授权。无真实数据/预算的 fixture 不能代替质量证据。

主线程统一拥有共享 schema/controller/launcher/scorer、文档与 Git；独立模块
可另行登记精确文件归属后并行。只读审查可与实现并行，不开重复写入者。
用户随后授权夜间补齐当前功能缺口；执行顺序和边界见
[夜间工程闭环队列](../../plans/overnight-engineering-closure.md)。每个新切片仍先
冻结接口、测试和归属，再实现，不自动启动真实语料、付费实验或训练。
r53 + EVAS 0.8.7、旧工作树和 stopped pilot 保持原样。
