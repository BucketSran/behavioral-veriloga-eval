## 顺序与可并行范围

1. 审查 AA-VAE-073–075 的分次 diff、免费联合用例与证据边界，不重复开发已完成工具接线。
2. 提供并审核真实 RAG 来源、许可、外部 API 权限和污染排除；Cadence 需要确切原文路径。
3. 复核当日模型/费率/解码，冻结正式组合任务与预算，再运行真实模型联合验收；归因问题单独设计对照。
4. 真实语义轨迹导出、SFT/RL 与新 read/edit 工具仍独立讨论；fixture 不能代替质量证据或训练授权。

可另行登记精确文件归属后并行。只读审查可与实现并行，不开重复写入者。
