# 功能迁移台账

- [AA-VAE-071](features/AA-VAE-071-comparison-engineering-gates.md)：旧/新对照的
  免费工程门槛：复用费用守卫、六格调度、实际输入/容器/请求审计、只读结果 join。
  脚本响应的真实 Docker/EVAS 六格链路通过；默认 pilot 不变、零付费调用。
  真实模型比较仍需 live adapter 与新的模型/价格/解码/费用授权，不是 baseline 复现。

- [AA-VAE-070](features/AA-VAE-070-batch-resume.md)：参考 Inspect/Harbor 的批次/
  trial 分层，补 Native/Evolution 完成项复用、缺失项调度与安全 attempt 边界恢复。
  复用原有证据校验/评分，不恢复未完成对话或 final；本地集成/独立复审通过，
  跨进程零重入和真实任务形式回归通过；没有付费实验或 hosted CI 声明。

- [AA-VAE-069](features/AA-VAE-069-legacy-native-comparison-protocol.md)：旧/新
  mini-swe 六单元工作流对照蓝图、公开源输入快照、实际请求差分与Docker挂载审计。
  协议/免费证据，不改生产代码；真实模型/预算/完整导出及跨backend结果join仍待完成。

- [AA-VAE-068](features/AA-VAE-068-legacy-native-r53-contracts.md)：旧
  `--agent-scaffold native` sensitivity 工具复用 r53 固定契约校验，补齐
  strict/portable 与 reference-only 分发；保留历史兼容，不替换默认 backend。

- [AA-VAE-067](features/AA-VAE-067-r53-portable-public-contracts.md)：修复 r53 已发布
  portable 公开契约的六题拒绝；全量契约覆盖、固定命令 fail-closed 与 profile/
  waveform/Evolution 回归。未改变行为评分、选择指标或 r53/EVAS。

- [AA-VAE-066](features/AA-VAE-066-information-surface-failure-reporting.md)：native/
  Evolution 配置绑定 expected information surface；记录未证明的信息面匹配，
  Evolution 失败责任复用统一 taxonomy，不将 candidate verdict 当基础设施异常。

- [AA-VAE-065](features/AA-VAE-065-synthetic-evolution-docs.md)：synthetic corpus
  显式接入 Evolution 分支，复用工具/预算/轨迹；hash 前冻结、分支本地检索、
  独立 final-result 身份和普通汇总混池拒绝。真实 Docker 双模型双轮通过。

- [AA-VAE-064](features/AA-VAE-064-evolution-generation-surface.md)：Evolution
  分支 export/environment 使用 NoEVAS 内部副本，公开/最终 checker 保持独立
  原始输入；修复生成说明与实际能力不一致，保留逻辑实验身份。

- [AA-VAE-063](features/AA-VAE-063-paired-report-case-index.md)：普通 native ledger
  新增配对统计和 reviewer-safe case hash 索引；完整分母、零分母 null、缺失证据
  明示。兼容两种生产证据布局，不输出 raw trajectory；33 项 focused tests 通过。
